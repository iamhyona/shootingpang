# SHOOTING PANG

SHOOTING PANG · 슈팅팡

실행: index.html을 브라우저에서 열면 인터넷 없이 플레이할 수 있습니다.
조작: 드래그 후 놓기 / 좌우 방향키와 SPACE / X로 현재와 다음 팡팡이 교환.
규칙: 같은 캐릭터 3개 이상 연결하면 제거. 천장과 연결이 끊긴 캐릭터는 낙하.
발사 횟수 안에 모든 캐릭터를 제거하면 다음 스테이지. 경계선 도달 또는 발사 소진 시 실패.
최고 점수는 현재 브라우저에만 저장됩니다. 온라인 순위나 대전은 포함하지 않습니다.

캐릭터: ../games/pang-art.js (팡팡이 공통 원본, 7개 게임 공유) — 박현아의 팡야팡야 SVG 원본.
게임: game.js — 게임 규칙, 조작, 효과.
스타일: style.css — 화면 톤과 반응형 배치.
캐릭터 변경 시 PangArt.pieceSVG(color, mood)의 인터페이스를 유지하면 규칙을 바꿀 필요가 없습니다.
팡팡이 캐릭터 원본 © 박현아. 비상업적 프로젝트.
